# Susu Group Manager

A simple Node.js program to manage a rotating savings group (susu).  
Each member contributes a fixed weekly amount. The pot is paid to one member per week in the order they joined.

---

## 📦 Setup

Clone the repo and install dependencies:

```bash
git clone https://github.com/ashborn-knight/Susu-Group.git
cd Susu-Group
npm install

```Run Tests
This project uses Jest for automated testing.
Run all test suites with:
npm test
